# career-skills
Skills for resume review and career planning / 履歷健檢與職涯規劃用技能庫

## Skills

| Skill | Description |
|---|---|
| [outstanding-resume](skills/outstanding-resume/SKILL.md) | Rewrite a software engineer's resume to show concrete results, based on [如何打造出色的履歷](https://www.cythilya.tw/2024/04/19/how-to-create-an-outstanding-resume/). Interviews the user for missing facts, then outputs a Chinese and English resume, change notes, and an interview script. |
| [career-advice](skills/career-advice/SKILL.md) | Career consulting for software engineers at any stage, based on Summer's CareerWise articles. Interviews the user, gives direct and concrete advice, and writes a 1-year + 3-month action plan. Hands resume work to outstanding-resume. |
