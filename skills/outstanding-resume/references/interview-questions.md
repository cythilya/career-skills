# Interview Questions

Pick only the questions that matter for this resume. Always tie the question to a
specific line in the resume. Ask in Traditional Chinese.

## Results and numbers (highest priority)

For each experience item with no result:

- 「<原句>」做完之後，有什麼可量化的改善？例如效能指標（LCP、FCP、bundle size）、bug 數、
  轉換率、營收、開發或部署時間、使用者數？
- 如果沒有數字，這件事解決了什麼問題？對使用者、團隊或公司帶來什麼改變？
- 這是你主導的、還是參與的？你具體負責哪一部分？
- 當時的技術難點是什麼？你怎麼解決？

If experience is organized by project, also ask:

- 「<專案名稱>」是在哪一份工作做的？你在這個專案裡最重要的 1–2 個成果是什麼？有數據嗎？
- 不同專案之間有類似的成果嗎？（例如都做過效能優化、都導入過測試）合計的效益是多少？

## Summary strengths

- 你覺得自己最強的 3–5 個專長是什麼？
- 主管或同事曾經稱讚過你哪些地方？
- 你最有成就感的一個專案是哪個？為什麼？

## Leadership and team

- 有帶過人、帶過專案、做過 mentor、辦過分享會或讀書會嗎？結果如何？
- 有建立或改善過團隊流程嗎？例如 code review、測試、CI/CD、文件、onboarding。

## Target role (only if the user skipped both JD and positioning strategy)

- 你想應徵什麼職位？前端、全端、資深、Tech Lead？
- 有偏好的工作型態嗎？遠端、混合、進辦公室？外商或跨國團隊？

## Gaps and off-target experience

- <非工程經歷> 的經驗，有哪些能和目標職位連結？例如溝通協調、排優先順序、UX。
- 履歷上 <期間> 的空白期在做什麼？有接案、開源貢獻、個人專案嗎？

## Education (new graduates)

- 有論文、研究、競賽、獎學金、獎項、實習、接案或打工經驗嗎？成果是什麼？

## Works

- 有部落格、GitHub、技術分享、演講、Podcast 嗎？請提供完整網址。

## Language and certificates

- 英文或其他語言有證照或分數嗎？例如多益、托福、IELTS。

## English version

- 你的英文名字是什麼？（英文履歷的姓名要怎麼寫，例如 `Chen, Hsin-Yi` 或 `Cindy Chen`）
  **Always ask this in round 1 if the resume has no English name** — it does not count
  toward the 10-question limit.
- 公司與學校的正式英文名稱是什麼？
- 職稱的英文寫法？
